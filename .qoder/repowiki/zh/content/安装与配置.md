## 依赖安装（uv、pip、conda）

### 推荐方法：使用 uv 包管理器

根据 `README.md` 文档，**强烈推荐使用 `uv` 包管理器**进行依赖安装。这是唯一被官方支持的方法，可以确保安装正确的依赖版本，避免因版本冲突导致的随机错误、缺少 GPU 加速等问题。

#### 1. 安装 uv

`uv` 是一个现代、快速的 Python 包管理器。您可以通过以下方式之一安装：

-   **通过 pip 安装（推荐快捷方式）：**
    ```bash
    pip install -U uv
    ```

#### 2. 安装项目依赖

进入项目根目录后，使用 `uv` 安装所有依赖：

```bash
# 克隆并进入项目
git clone https://github.com/index-tts/index-tts.git
cd index-tts

# 下载大文件
git lfs pull

# 安装所有依赖（包括 WebUI 和 DeepSpeed）
uv sync --all-extras
```

**国内用户加速安装：**

如果下载速度较慢，可以使用国内镜像源：

```bash
uv sync --all-extras --default-index "https://mirrors.aliyun.com/pypi/simple"
# 或者
uv sync --all-extras --default-index "https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple"
```

**可选功能：**

-   `--extra webui`: 添加 WebUI 支持（推荐）。
-   `--extra deepspeed`: 添加 DeepSpeed 支持（可能加速推理）。

**Windows 用户注意：** DeepSpeed 在 Windows 上可能难以安装，如果遇到问题，可以省略 `--all-extras`，或仅安装 `--extra webui`。

## 模型下载与配置

### 下载预训练模型

模型权重需要单独下载，并放置在 `checkpoints/` 目录下。

#### 方法一：使用 Hugging Face CLI

```bash
# 安装 huggingface_hub CLI 工具
uv tool install "huggingface_hub[cli]"

# 下载模型到 checkpoints 目录
hf download IndexTeam/IndexTTS-2 --local-dir=checkpoints
```

#### 方法二：使用 ModelScope CLI

```bash
# 安装 modelscope 工具
uv tool install "modelscope"

# 下载模型到 checkpoints 目录
modelscope download --model IndexTeam/IndexTTS-2 --local_dir checkpoints
```

### 模型文件结构

下载完成后，`checkpoints/` 目录应包含以下关键文件：
-   `config.yaml`: 模型配置文件。
-   `gpt.pth`: GPT 模型权重。
-   `s2mel.pth`: S2Mel 模型权重。
-   `feat1.pt`, `feat2.pt`: 说话人和情感特征矩阵。
-   `qwen0.6bemo4-merge/`: Qwen 情感模型。

## 配置文件解析（config.yaml）

`checkpoints/config.yaml` 文件定义了模型的超参数和数据处理配置。以下是关键参数的解释：

### 数据集配置 (dataset)
-   `sample_rate`: 音频采样率，单位为 Hz。
-   `mel.n_mels`: 梅尔频谱图的频带数量。

### GPT 模型配置 (gpt)
-   `model_dim`: 模型的隐藏层维度。
-   `max_mel_tokens`: 生成梅尔频谱图的最大 token 数。
-   `max_text_tokens`: 输入文本的最大 token 数。
-   `layers`: Transformer 层数。
-   `condition_module`: 用于处理说话人提示音频的模块配置。
-   `emo_condition_module`: 用于处理情感提示音频的模块配置。

### 语音编解码器配置 (semantic_codec)
-   `codebook_size`: 语义码本的大小。

### S2Mel 模型配置 (s2mel)
-   `length_regulator`: 长度调节器，用于控制语音时长。
-   `DiT`: Diffusion Transformer 的配置，包括层数 (`depth`)、注意力头数 (`num_heads`) 等。
-   `wavenet`: 最终声码器的配置。

### 其他关键参数
-   `gpt_checkpoint`: GPT 模型权重文件名。
-   `s2mel_checkpoint`: S2Mel 模型权重文件名。
-   `vocoder.type`: 声码器类型，此处为 `bigvgan`。
-   `vocoder.name`: Hugging Face 上声码器模型的名称。

## 验证安装

### 检查 GPU 加速

运行提供的 `gpu_check.py` 脚本来验证 PyTorch 是否能正确识别您的 GPU。

```bash
uv run tools/gpu_check.py
```

该脚本会扫描并列出所有可用的硬件加速设备（如 NVIDIA CUDA、AMD ROCm、Apple MPS）。如果检测到设备，说明您的环境已准备好使用 GPU 加速。

### 运行 WebUI 演示

最直接的验证方法是启动 WebUI。

```bash
uv run webui.py
```

如果成功，您可以在浏览器中访问 `http://127.0.0.1:7860` 来使用图形化界面进行语音合成。

**Windows 用户快速启动：**

双击 `启动.bat` 脚本即可一键启动 WebUI。该脚本设置了必要的环境变量（如 `HF_HOME` 指向 `hf_cache` 目录）并调用 Python 执行 `webui.py`。

## 常见问题与故障排除

### 1. CUDA 安装错误

**问题：** 安装依赖时出现 CUDA 相关错误。
**解决方案：** 确保您的系统已安装 **NVIDIA CUDA Toolkit 12.8 或更高版本**。`pyproject.toml` 文件中明确指定了从 `https://download.pytorch.org/whl/cu128` 安装 PyTorch，因此需要匹配的 CUDA 版本。

### 2. 依赖冲突或随机错误

**问题：** 使用 `pip` 或 `conda` 安装后出现各种奇怪的错误。
**解决方案：** 严格按照文档要求，使用 `uv` 包管理器进行安装。`uv` 能够精确锁定依赖版本，避免此类问题。

### 3. 模型下载缓慢

**问题：** 从 Hugging Face 下载模型速度很慢。
**解决方案：** 在运行代码前，设置环境变量以使用国内镜像：
```bash
export HF_ENDPOINT="https://hf-mirror.com"
```

### 4. WebUI 无法启动

**问题：** 运行 `uv run webui.py` 时出错。
**解决方案：**
-   确认 `uv sync --all-extras` 已成功执行，`gradio` 包已安装。
-   检查 `checkpoints/` 目录下是否已正确下载所有模型文件。
-   查看具体的错误日志信息。

### 5. “No devices found” 错误

**问题：** `gpu_check.py` 显示未找到设备。
**解决方案：**
-   确认您的 GPU 驱动程序已正确安装。
-   确认安装的 PyTorch 版本支持您的 GPU 和 CUDA 版本。
-   如果使用的是集成显卡或 Apple Silicon，请确认 PyTorch 是否支持（如 MPS）。

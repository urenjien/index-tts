## 简介
`indextts/cli.py` 提供了一个命令行接口，用于调用 IndexTTS 语音合成模型。用户可以通过命令行指定输入文本、参考音频路径、输出路径等参数，快速生成高质量的语音文件。该工具基于 `argparse` 构建，支持多种可配置选项，适用于自动化任务和服务器端批量处理。

## 命令行参数说明
以下是 `cli.py` 中定义的所有命令行参数及其默认值：

| 参数 | 类型 | 是否必需 | 默认值 | 说明 |
|------|------|----------|--------|------|
| `text` | 字符串 | 是 | 无 | 要合成的文本内容 |
| `-v`, `--voice` | 字符串 | 是 | 无 | 参考音频文件路径（WAV 格式） |
| `-o`, `--output_path` | 字符串 | 否 | `gen.wav` | 输出音频文件路径 |
| `-c`, `--config` | 字符串 | 否 | `checkpoints/config.yaml` | 配置文件路径 |
| `--model_dir` | 字符串 | 否 | `checkpoints` | 模型目录路径 |
| `--fp16` | 布尔值 | 否 | `False` | 是否使用 FP16 进行推理（如果可用） |
| `-f`, `--force` | 布尔值 | 否 | `False` | 如果输出文件已存在，是否强制覆盖 |
| `-d`, `--device` | 字符串 | 否 | 自动检测 | 运行模型的设备（cpu, cuda, mps, xpu） |

这些参数通过 `argparse.ArgumentParser` 定义，并在运行时进行验证，确保输入的有效性。

## 使用语法与示例
### 基本语法
```bash
python cli.py <text> -v <voice_path> [options]
```

### 实际调用示例
#### 示例 1：基本语音合成
```bash
python cli.py "你好，欢迎使用IndexTTS。" -v examples/voice_01.wav -o output.wav
```
此命令将使用 `examples/voice_01.wav` 作为参考音频，合成指定文本并保存为 `output.wav`。

#### 示例 2：指定配置文件和模型目录
```bash
python cli.py "这是另一个测试。" -v examples/voice_02.wav -o result.wav --config my_config.yaml --model_dir my_checkpoints
```
此命令使用自定义配置文件和模型目录进行语音合成。

#### 示例 3：启用 FP16 加速并强制覆盖输出
```bash
python cli.py "启用FP16加速。" -v examples/voice_03.wav -o gen.wav --fp16 -f
```
此命令启用 FP16 推理并允许覆盖已存在的输出文件。

#### 示例 4：指定运行设备
```bash
python cli.py "在CPU上运行。" -v examples/voice_04.wav -o cpu_output.wav -d cpu
```
此命令强制在 CPU 上运行模型。

## 批量语音合成
可以通过脚本循环调用命令行工具来实现批量语音合成。以下是一个 Python 脚本示例，用于处理多个文本文件：

```python
import os
import subprocess

text_files = ["text1.txt", "text2.txt", "text3.txt"]
voice_path = "examples/voice_01.wav"
output_dir = "batch_output"

os.makedirs(output_dir, exist_ok=True)

for i, text_file in enumerate(text_files):
    with open(text_file, 'r', encoding='utf-8') as f:
        text = f.read().strip()
    
    output_path = os.path.join(output_dir, f"output_{i+1}.wav")
    
    cmd = [
        "python", "indextts/cli.py",
        text,
        "-v", voice_path,
        "-o", output_path,
        "--force"
    ]
    
    result = subprocess.run(cmd, capture_output=True, text=True)
    if result.returncode == 0:
        print(f"成功生成: {output_path}")
    else:
        print(f"失败: {result.stderr}")
```

该脚本读取多个文本文件，依次调用 `cli.py` 生成对应的语音文件，并保存到指定目录中。

## 输出文件命名与保存位置
默认情况下，输出音频文件命名为 `gen.wav`，并保存在当前工作目录下。用户可以通过 `-o` 或 `--output_path` 参数指定自定义的输出路径和文件名。如果指定的输出目录不存在，程序会自动创建该目录。

例如：
- `-o /path/to/output.wav` 将音频保存到 `/path/to/` 目录下。
- `-o results/audio1.wav` 将音频保存到 `results` 子目录中。

如果输出文件已存在且未使用 `-f` 参数，程序将报错并退出，防止意外覆盖。

## 适用场景
该命令行工具最适合以下使用场景：
- **自动化任务**：集成到 CI/CD 流程或定时任务中，自动批量生成语音内容。
- **服务器端批量处理**：在服务器上运行大规模语音合成任务，支持高并发调用。
- **离线语音生成**：无需图形界面，适合在无 GUI 环境中运行。
- **脚本化操作**：通过 Shell 或 Python 脚本调用，实现灵活的语音合成流程。

由于其轻量级和高效的特点，该工具特别适合需要频繁调用语音合成服务的应用场景。

## 错误处理指南
以下是常见错误及其解决方案：

### 1. 文本为空
**错误信息**：
```
ERROR: Text is empty.
```
**解决方案**：确保提供的文本非空。

### 2. 参考音频文件不存在
**错误信息**：
```
Audio prompt file <path> does not exist.
```
**解决方案**：检查音频文件路径是否正确，确保文件存在且为 WAV 格式。

### 3. 配置文件不存在
**错误信息**：
```
Config file <path> does not exist.
```
**解决方案**：确认配置文件路径正确，或使用默认路径 `checkpoints/config.yaml`。

### 4. 输出文件已存在且未强制覆盖
**错误信息**：
```
ERROR: Output file <path> already exists. Use --force to overwrite.
```
**解决方案**：添加 `-f` 参数以强制覆盖，或更改输出文件名。

### 5. PyTorch 未安装
**错误信息**：
```
ERROR: PyTorch is not installed. Please install it first.
```
**解决方案**：安装 PyTorch：
```bash
pip install torch torchaudio
```

### 6. 设备不支持
**警告信息**：
```
WARNING: Running on CPU may be slow.
```
**解决方案**：如果可能，使用 CUDA 或 MPS 设备以提高性能。

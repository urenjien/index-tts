## 简介

IndexTTS2 是一个突破性的零样本文本转语音（TTS）系统，支持情感表达和语音时长控制。本指南将详细介绍三种主要的交互方式：通过 `webui.py` 提供的 Gradio Web 界面、通过 `indextts/infer_v2.py` 提供的 Python API 以及通过 `indextts/cli.py` 提供的命令行工具。每种方式都提供了清晰的步骤说明和实际操作示例，帮助用户快速上手并根据需求选择最适合的使用方式。

## 通过Web界面使用

### 启动Web界面

要启动 Web 界面，请运行以下命令：

```bash
python webui.py
```

或者使用 `uv` 工具运行：

```bash
uv run webui.py
```

启动后，打开浏览器访问 `http://127.0.0.1:7860` 即可看到 Web 界面。

### Web界面功能说明

Web 界面提供了直观的操作方式，用户可以通过上传或录制音色参考音频、输入目标文本、选择情感控制方式等来生成语音。界面主要包含以下几个部分：

- **音色参考音频**：上传或录制一段音频作为音色参考。
- **文本输入**：输入要合成的目标文本。
- **情感控制方式**：可以选择与音色参考音频相同、使用情感参考音频、使用情感向量控制或使用情感描述文本控制。
- **高级生成参数设置**：可以调整 GPT2 采样设置和分句设置等高级参数。

### 操作流程示例

1. 上传一段音色参考音频。
2. 在文本框中输入目标文本。
3. 选择情感控制方式为“使用情感参考音频”。
4. 上传一段情感参考音频。
5. 点击“生成语音”按钮，等待生成结果。

## 通过Python API使用

### 实例化IndexTTS2类

在 Python 脚本中，首先需要导入 `IndexTTS2` 类并实例化：

```python
from indextts.infer_v2 import IndexTTS2

tts = IndexTTS2(cfg_path="checkpoints/config.yaml", model_dir="checkpoints", use_fp16=False, use_cuda_kernel=False, use_deepspeed=False)
```

### 调用infer方法进行语音合成

实例化完成后，可以调用 `infer` 方法进行语音合成：

```python
text = "Translate for me, what is a surprise!"
output_path = "gen.wav"
tts.infer(spk_audio_prompt='examples/voice_01.wav', text=text, output_path=output_path, verbose=True)
```

### 参数说明

- `spk_audio_prompt`：音色参考音频路径。
- `text`：要合成的目标文本。
- `output_path`：生成的音频文件保存路径。
- `verbose`：是否启用详细模式。

### 高级用法示例

#### 使用情感参考音频

```python
tts.infer(spk_audio_prompt='examples/voice_07.wav', text="酒楼丧尽天良，开始借机竞拍房间，哎，一群蠢货。", output_path="gen.wav", emo_audio_prompt="examples/emo_sad.wav", verbose=True)
```

#### 使用情感向量控制

```python
tts.infer(spk_audio_prompt='examples/voice_10.wav', text="哇塞！这个爆率也太高了！欧皇附体了！", output_path="gen.wav", emo_vector=[0, 0, 0, 0, 0, 0, 0.45, 0], use_random=False, verbose=True)
```

#### 使用情感描述文本控制

```python
tts.infer(spk_audio_prompt='examples/voice_12.wav', text="快躲起来！是他要来了！他要来抓我们了！", output_path="gen.wav", emo_alpha=0.6, use_emo_text=True, use_random=False, verbose=True)
```

## 通过命令行工具使用

### 命令行工具使用语法

要使用命令行工具，运行以下命令：

```bash
python indextts/cli.py <text> -v <voice> -o <output_path> [options]
```

### 参数说明

- `text`：要合成的目标文本。
- `-v, --voice`：音色参考音频路径（wav 格式）。
- `-o, --output_path`：生成的音频文件保存路径，默认为 `gen.wav`。
- `-c, --config`：配置文件路径，默认为 `checkpoints/config.yaml`。
- `--model_dir`：模型目录路径，默认为 `checkpoints`。
- `--fp16`：是否使用 FP16 进行推理（如果可用）。
- `-f, --force`：如果输出文件已存在，是否强制覆盖。
- `-d, --device`：运行模型的设备（cpu, cuda, mps, xpu）。

### 使用示例

```bash
python indextts/cli.py "欢迎大家来体验indextts2，并给予我们意见与反馈，谢谢大家。" -v examples/voice_01.wav -o output.wav --fp16
```

此命令将使用 `examples/voice_01.wav` 作为音色参考音频，合成指定文本的语音，并将结果保存到 `output.wav` 文件中，同时启用 FP16 推理以提高性能。

## 三种使用方式的适用场景

### Web界面

- **适用场景**：适合快速体验和演示，无需编写代码即可完成语音合成。
- **优点**：操作简单，界面友好，适合非技术人员使用。
- **缺点**：灵活性较低，不适合集成到其他项目中。

### Python API

- **适用场景**：适合将 IndexTTS2 集成到其他 Python 项目中，如自动化脚本、Web 应用等。
- **优点**：高度灵活，可以自定义各种参数，适合开发人员使用。
- **缺点**：需要一定的编程基础。

### 命令行工具

- **适用场景**：适合批量处理任务，如批量生成语音文件。
- **优点**：可以在命令行环境中快速执行，适合自动化脚本和批处理任务。
- **缺点**：需要记住命令行参数，不适合复杂的交互式操作。

## 总结

本文档详细介绍了 IndexTTS2 的三种主要使用方式：通过 Web 界面、Python API 和命令行工具。每种方式都有其独特的适用场景和优缺点。用户可以根据自己的需求选择最合适的方式进行语音合成。无论是快速体验、项目集成还是批量处理，IndexTTS2 都能提供强大的支持。
